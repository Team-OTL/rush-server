# rush-eureka

Eureka 서비스 레지스트리. Spring 서비스들이 여기에 등록되고, 게이트웨이는 `lb://서비스이름`으로 찾아갑니다.

대시보드: http://localhost:8761

- 서비스는 10초마다 하트비트를 보내고, 30초 동안 없으면 5초 주기 정리 작업에서 빠집니다.
- 서비스가 정상 종료하면 바로 등록이 해제됩니다. 응답 없이 죽으면 하트비트 만료와 게이트웨이 목록 갱신(5초)·캐시(5초)를 거쳐 1분 안에 라우팅에서 빠집니다.
- 자기 보존 모드는 로컬에서 꺼 둡니다. 운영에서는 `EUREKA_SELF_PRESERVATION=true`로 켭니다.

## 실행

```bash
./gradlew :rush-eureka:bootRun
```
